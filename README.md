# 3MR web dashboard

Web build 1.1.1 of the 3MR MaxxECU dashboard.

- **Live car data:** open the address shown by the 3MR bridge phone on the same WiFi/hotspot (e.g. `http://192.168.43.1:8080`).
- **On this site:** Setup → Connect → "No ECU (GPS only)" gives a GPS speedometer and live map using this device's location. Setup → Device → Debug → Demo ECU shows simulated engine data.
- **Android app:** [3MR.apk](3MR.apk) (1.1.1) — also linked in Setup → Device.

Map data © OpenStreetMap contributors.
